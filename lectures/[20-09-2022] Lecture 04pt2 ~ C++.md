## I/O in C++

* We have 3 streams
 

 > In shell, we had `stdin`, `stdout`, `stderr`

 > In C++, we have the following streams:
 
 * `cout` - standard output
 * `cerr` - standard error
 * `cin` - standard input

 * `stream << value` writes an expression **to** the stream. **(Output operator)**
 * `stream >> variable` reads into the variable. **(Input operator)**

## `cin.fail()`
* Indicates if an operation has failed a cin
* see `readInts.cc`

```cpp
#include <iostream>
using namespace std;

int main() {
  int i;
  while (true) {
    cin >> i;
    if (cin.fail()) break;
    cout << i << endl;
  }
}
```

* Control + D also kills the program

* You can also use redirection to pass stuff into stdin into a c++ program.

## Chaining input operations
* Let's look at `plus.cc` again, but let's add brackets

```cpp
#include <iostream>
using namespace std;

int main () {
  int x, y;
  (cin >> x) >> y;
  (cout << x + y) << endl;
}
```

* When a stream finishes an output, it returns the `stream` itself, so you can chain them together.
